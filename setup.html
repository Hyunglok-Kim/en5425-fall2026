Setup

Everything on this page should be done before the Week 1 lab and is verified by HW0. Work through it top to bottom with your AI agent beside you — driving an agent through setup is itself the first exercise of the course.

1 · Environment

Python 3.11 in an isolated environment named en5425, created with conda or uv — your choice, but you must be able to export and rebuild it (HW0 checks this from a fresh clone).

# Option A — conda (Miniconda is enough)
conda create -n en5425 python=3.11
conda activate en5425
pip install torch numpy pandas xarray matplotlib
conda env export --from-history > environment.yml   # commit this

# Option B — uv
uv init en5425 --python 3.11 && cd en5425
uv add torch numpy pandas xarray matplotlib
# pyproject.toml + uv.lock are your export — commit both

Configure git with your real name and university email — commit history is graded evidence in this course.

git config --global user.name  "Your Real Name"
git config --global user.email "you@gm.gist.ac.kr"
  • Editor: VS Code or the editor of your choice — anything you are fast in.
  • AI coding agent (required, at least one): Claude Code, Codex, or Cursor. Agents are mandatory tooling here — and you remain accountable for every line they write (see the AI coding agent policy).

3 · Your semester repository

All of your graded written work — memos, research notes, labs, the capstone — lives in one private GitHub repository that you own.

  1. Open the template repo en5425-student-template in the course GitHub organization and click Use this template → Create a new repository. Name it en5425-<your-github-username> and set it to Private.
  2. Invite the instructor as a collaborator (Settings → Collaborators; the instructor's GitHub handle is announced in class and on LMS).
  3. Clone it over SSH and work in it all semester.
your-repo/
├── labs/        # one folder per weekly lab (code, figures)
├── memos/       # weekNN.md — reading memos
├── notes/       # research notes, one per lab
├── project/     # capstone: proposal, milestones, final report
└── hw0/         # the gate assignment

Conventions — these are graded habits, not suggestions:

  • memos/weekNN.md pushed 24 h before class; the push timestamp is the submission time.
  • A research note in notes/ after every lab, using the course template (What I did / What I learned / What confused me / Open questions).
  • Commit at every lab checkpoint with informative messages — commit history is part of AI-agent accountability, and one giant "final" commit reads as exactly what it is.
  • Never commit data or model checkpoints. The template ships a .gitignore that covers data/, *.ckpt, *.pt, and friends — keep it intact.

4 · Course materials

Lecture notebooks, lab scaffolds, and the smoke test live in the course repo. Clone it once and pull weekly:

git clone git@github.com:gist-en5425/course.git
cd course && git pull        # run before every session
Never edit inside the clone. Copy notebooks and scaffolds out into your own repo (e.g., into labs/weekNN/) before touching them — local edits will collide with the weekly git pull, and your work belongs in your repository, where it is graded.
